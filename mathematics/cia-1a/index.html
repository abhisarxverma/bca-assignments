3. Simplification via De Morgan's Laws

To understand when the system produces No Alert (¬A), we simplify the negation of the Master Formula using De Morgan's Laws:

¬A ≡ ¬((P ∧ Q) ∨ S ∨ (T ∧ R))
¬A ≡ ¬(P ∧ Q) ∧ ¬S ∧ ¬(T ∧ R)  (De Morgan's Disjunction)
¬A ≡ (¬P ∨ ¬Q) ∧ ¬S ∧ (¬T ∨ ¬R)  (De Morgan's Conjunction)

Meaning: No Alert (¬A) is generated if and only if there is no thunderstorm (¬S), AND either rain or wind is below threshold, AND either visibility or temperature is safe.

5. Discussion, Limitations & Fuzzy Logic Extension
Limitation of Crisp Propositional Logic:

Crisp logic requires strict boundaries. For example, under proposition P (Rain > 80%), a reading of 80.1% evaluates to TRUE while 79.9% evaluates to FALSE. In real meteorological systems, physical phenomena exist along a continuous spectrum.

Future Scope — Fuzzy Logic:

To prevent sharp boundary errors, real-world weather systems like IMD integrate Fuzzy Logic where truth values range smoothly between 0.0 and 1.0, allowing continuous transitions in danger severity.
